# London Bikes Hire Scheme: Hiring Trends & Analytics :bike:

### :information_source: Data Source
The present study leverages bike hiring information from https://tfl.gov.uk/

### :bulb: Description
The objective of this report is to delve into the data recorded and relates to bikes hired in London between 2013 and 2018. The report provides statistical and visual devices to identify significant data trends and patterns, which in turn provide useful insights for the design and function of the bike hiring scheme.

### :white_check_mark: Contents

1. Exploratory Data Analysis
   1. Time series view and summary statistics
   2. Box Plot and Density Plot analyses
   3. Confidence Intervals
